# Shapes

Confetti shapes from the graphics palette: decorative accents for
celebration moments, mostly in learner-facing work. Always `aria-hidden`;
they never carry meaning. Use them as-is in both themes; don't make up
new shapes.

These are uploads: to get one, read `project/design-system.json`, take `assetGroups.Shapes.files["<name>"].blob`, and `read` that id as the path. In an artifact, inline the SVG or use a `data:` URI.
