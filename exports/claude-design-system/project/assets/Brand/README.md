# Brand

Khan Academy and Khanmigo marks. Copy these files; never redraw, recolor or
approximate a mark.

- `khan-academy-logo-mark.svg`: the hexagon mark, single ink `#191918`, for light (`thunderblocks`) surfaces.
- `khan-academy-logo-mark-on-dark.svg`: the same mark in the dark default foreground, for `syl-dark` surfaces.
- `khanmigo.svg`: Khanmigo, the AI tutor. Multicolor; the same file works in both themes.

Which file goes where: "Brand marks" in the README.

These are uploads: to get one, read `project/design-system.json`, take `assetGroups.Brand.files["<name>"].blob`, and `read` that id as the path. In an artifact, inline the SVG or use a `data:` URI.
