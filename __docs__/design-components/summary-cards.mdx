# Summary cards

<NeutralBadge label="The headline at a glance" />

Summary cards answer "What's the headline?" They show key numbers in words and digits, with no chart to decode. Detail is one click away.

Summary cards are built with Wonder Blocks, using the Thunderblocks theme.

## <Do /> When to use

| Use when | Example use |
| --- | --- |
| One value tells the story, and a few of them sit side by side | District overview: Students assessed, Subjects on target, District growth |
| Readers compare a few subjects or classes on the same measures | Algebra 1, Geometry, and HS ELA, each with an average score and level |

## <Dont /> When NOT to use

| Don’t use when | Recommended alternative | Rationale |
| --- | --- | --- |
| Readers need to see change over time | [Trend charts](?path=/docs/design-guidelines-components-data-visualization-trend-charts--docs) | A card shows one moment. A line shows the direction across periods. |
| Readers need to see how a group is spread out | [Distribution charts](?path=/docs/design-guidelines-components-data-visualization-distribution-charts--docs) | A card can't show the spread across ranges. |
| Readers need to find or act on individuals or items | [Data tables](?path=/docs/design-guidelines-components-data-visualization-data-tables--docs) | Cards summarize groups. Tables list each individual or item to act on. |

## Placement

Summary cards are the headline, so readers should see them almost immediately.

<ul>
    <li><Do /> Place summary cards at the top of the page, below the page title and other top-of-page elements.</li>
    <li><Dont /> Place summary cards below detailed components, like chart containers or data tables.</li>
</ul>

See [Page order](?path=/docs/design-guidelines-patterns-data-reports--docs#page-order) in Data reports.

## Variants

### Stat card

Shows one metric. Stat cards sit in a row of 2 to 4, under a section heading that names the group, like "District overview."

| Part | Required | Example |
| --- | --- | --- |
| Label | Yes | Students assessed |
| Info tooltip | Optional. Beside the label, for more context. | How the metric is calculated |
| Value | Yes | 11,033; 2 of 3; −7 pts |
| Context or change | Optional | 40% of total students assessed; ↓ 1 subject at risk |
| Caret right icon | When the card is clickable | › |

- Use at least 2 and at most 4 stat cards in a row.
- Stat cards have no controls and no last-updated footer.
- Format the value with the [Number formatting](?path=/docs/design-guidelines-foundations-data-visualization--docs#number-formatting) rules: "11,033," "1.2K," "−7 pts."
- Show a change as a [value and trend badge](?path=/docs/design-guidelines-components-feedback-badges--docs#value-and-trend-badges). Only the value and its arrow go inside the badge ("↓ 1"). The description stays outside as text ("subject at risk").
- Give a rank its total: "8th of 24 classes," not "8th."
- Pair a change arrow with text. The arrow and its color never carry the meaning alone.
- Use a [Warning](?path=/docs/design-guidelines-components-feedback-badges--docs#warning-status) badge when a metric has gone down or is at risk, and a [Success](?path=/docs/design-guidelines-components-feedback-badges--docs#success-status) badge when it has gone up.

#### Clickable stat cards

- Make a stat card clickable only when there's a detail view for that metric.
- Show a caret right icon on every clickable card, at the top right. A card without one isn't clickable.
- Make every card in a row clickable, or none. If one metric has no detail view, the row isn't clickable.

### Comparison card

Shows one subject or class with a few key numbers and an insight sentence. Stack comparison cards in a list under a section heading to compare them.

| Part | Required | Example |
| --- | --- | --- |
| Name | Yes | Algebra 1 |
| Count | Yes | 7,211 students assessed |
| Key metric | Yes | Avg 820 |
| Level | When the metric maps to a level | Demonstrating |
| Insight sentence | Yes | Climbing steadily — up 10 points, with 35% of students now scoring at grade level. |
| Link | Yes | Chevron to the full report |

<ul>
    <li><Do /> Show the same metrics in the same order on every card in the list.</li>
    <li><Do /> Write the level as a word, so color is never the only signal.</li>
    <li><Do /> Let the insight sentence carry the change: "up 10 points."</li>
    <li><Dont /> Put a chart in a comparison card. Link to the full report instead.</li>
</ul>

## Accessibility

- A clickable card is one link target with an accessible name, like "Algebra 1 report" or "Students assessed details." The caret right icon is decorative.
- A stat card that isn't clickable isn't focusable.
- Read the level and the change as text, not as color or an arrow icon.
