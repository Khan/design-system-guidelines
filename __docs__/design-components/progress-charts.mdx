# Progress charts

<NeutralBadge label="Progress toward a goal" />

Progress charts answer "How close are we to the goal?" A progress bar shows a current value against a goal, and can mark where the group should be by today. Progress means how far along, never how well. A progress chart never shows a score or outcome.

Progress charts sit inside a [chart container](?path=/docs/design-guidelines-components-data-visualization-chart-container--docs), large or small. They're built with Wonder Blocks, using the Thunderblocks theme.

## <Do /> When to use

| Use when | Example use |
| --- | --- |
| Readers need to see how far along they are toward a goal | Gems toward a class challenge, or assignments completed toward a school or district goal |
| Readers need to see whether progress is on track for a deadline | Skills mastered against today's target |
| Readers need to see how much of a task is done | Students who finished an assignment or assessment |

## <Dont /> When NOT to use

| Don’t use when | Recommended alternative | Rationale |
| --- | --- | --- |
| Readers only need to know ahead or behind, not how far along the goal they are, like "The class is 3 skills ahead of target" | A [stat card](?path=/docs/design-guidelines-components-data-visualization-summary-cards--docs#stat-card) | Plain text is faster to read than a chart to decode. Use a bar when seeing how much of the goal is left matters. |
| Showing a score or outcome, like Beginning, Approaching, or Demonstrating | [Distribution charts](?path=/docs/design-guidelines-components-data-visualization-distribution-charts--docs#grouped-by-level) grouped by level, or a [comparison card](?path=/docs/design-guidelines-components-data-visualization-summary-cards--docs#comparison-card) | A bar reads as how far along, not how well. A full bar would look like success even when scores are low. |
| There's no goal or target | [Summary cards](?path=/docs/design-guidelines-components-data-visualization-summary-cards--docs) | Progress needs something to measure against. Without a goal, a bar's length means nothing. |
| Readers need to see how progress changed over time | [Trend charts](?path=/docs/design-guidelines-components-data-visualization-trend-charts--docs) | A progress bar shows where things stand today, not how they got there. |

## Anatomy

| Part | Rule | Example |
| --- | --- | --- |
| Value and goal | Always as text, not only as bar length | 1,245 of 1,500 gems |
| Bar | Fills to the current value. Choose colors by role. See [Color](?path=/docs/design-guidelines-foundations-data-visualization--docs#color). | |
| Today's target marker | When "on track" depends on the date. Labeled with its value. | Today's target: 35 |
| Start and end labels | In large containers, when the bar spans a time period | 0 skills, Sept 1; 70 skills, May 29 |

Gem challenges and other motivation goals use the [Motivation](?path=/docs/design-guidelines-foundations-data-visualization--docs#motivation) color role.

### Today's target

Today's target is where the group should be by today to reach the goal on time. It spreads the goal evenly across school days, so it doesn't move on weekends or holidays.

### Large container

For reports. The title states where the group stands against today's target.

| Part | Example |
| --- | --- |
| Section heading | Grade level target |
| Title | 3 skills ahead of target |
| Description | 38 of 70 skills · Target date May 29 |
| Bar | With a labeled today's target marker, and start and end labels |
| Footer | Updated today, 9:15 AM |

Label the bar's values directly. A legend isn't needed when the value and the marker are labeled.

### Small container

For dashboards and side panels, like the student dashboard. Keep it to the bar and a few values.

| Part | Example |
| --- | --- |
| Title | Gem challenge |
| Context | QAing |
| Bar | No marker |
| Value and goal | 52 of 80 gems |
| Time left | 12 days left |
| Details | Up to two rows, like Your contribution: 9 gems and Reward: October certificate |

<ul>
    <li><Do /> Keep a small container to one bar and up to four values.</li>
    <li><Dont /> Add controls, a legend, or a today's target marker to a small container. If readers need them, use a large container.</li>
</ul>

## Usage guidelines

<ul>
    <li><Do /> Show the current value and the goal as text, not only as bar length.</li>
    <li><Do /> Label the today's target marker with its value: "Today's target: 35."</li>
    <li><Do /> State the gap in the title of a large container: "3 skills ahead of target," not "Class is ahead of target."</li>
    <li><Dont /> Fill the bar past 100%. Say "Goal reached" and show the final value.</li>
    <li><Dont /> Show progress as a gauge or dial. Gauges are harder to read and compare, and take more space for the same value.</li>
</ul>

## Accessibility

- Every progress chart has a text summary: "38 of 70 skills. Today's target is 35. 3 skills ahead of target."
- Read the value and goal as text: "0 of 80 gems."
- Announce the today's target marker with its value: "Today's target: 35."
- Color is never the only signal. The title or values say whether the group is ahead or behind.
