# Search field

<NeutralBadge label="Keyword filtering" />

A specialized text input used to accept user-entered keywords or strings to instantly narrow or filter content based on those terms. It is the primary mechanism for finding specific items within large data sets or complex navigation structures.

## When to use

The choice to use a search field is determined by the need to efficiently locate specific information that cannot be easily found using predefined filters or navigation.

| Use when | Example use |
| --- | --- |
| The content list contains more than 10–15 items, making visual scanning difficult | Finding a specific student name within a class roster of 40 students. |
| The user is searching by a specific identifier, name, or non-categorical string | Searching for "Pythagorean Theorem" in a library of math lessons. |
| The dataset is too large for live-filtering and requires explicit submission | Typing a partial class name and hitting enter to refresh the report table. |

## When NOT to use

| Don't use when | Recommended alternative | Rationale |
| --- | --- | --- |
| The available options are fixed, small, and mutually exclusive | Dropdown, checkbox, or radio group | Don't use a search field when the options are fixed, small, and mutually exclusive (e.g., selecting "Draft" or "Published" status). |
| The user is narrowing a preference with a binary choice | Toggle / checkbox | For binary choices like "Show assigned skills only," use a toggle instead of a search query. |
| The input is intended to collect new data, not retrieve existing data | Standard text input | Don't use search-field styling for inputs that collect new data (e.g., "Student name" on a registration form). Search is for retrieval. |

## States

### Default / active

The search field is bordered and displays placeholder text like "Search." When active, the input must change appearance to clearly indicate active typing.

<img src={defaultActiveImg} alt="Two search fields: a default field with a magnifier icon and placeholder, and an active field showing a text cursor and a clear icon" />

### Scope clarity

Optionally add placeholder text (e.g., "Search students…") or an adjacent scope selector to make clear what the field searches.

<img src={scopeClarityImg} alt="A search field whose placeholder reads “Search report,” clarifying its scope" />

## Placement

### Contextual placement

The search field must be placed immediately adjacent to the content list or data set it controls. It should never float or sit distant from the elements it is meant to filter.

<img src={contextualPlacementImg} alt="A report page with the search field placed directly above the results table it filters, alongside the other filter controls" />

## Interactions

### Auto-suggestion

As the user types, a menu appears below the field containing high-confidence matches. These can include metadata labels (e.g., "Class") to give context for each suggestion.

<img src={autoSuggestionImg} alt="A search field with “A” typed, showing a suggestion menu of Algebra 1, Advanced Algebra 1, AP Calculus, and Pre-Algebra Basics, each tagged “Class”" />

### Clear button

Once text is entered, a visible clear/reset button (an "X") should appear inside the input field so the user can easily erase the query and restore the full list.

<img src={clearButtonImg} alt="A search field with a text cursor and a clear “X” button at the end of the input" />
