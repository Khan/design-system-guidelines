# Chart container

<NeutralBadge label="Frame for a chart" />

A container holds one chart with its heading, title, controls, and footer. Every distribution chart, trend chart, and progress target bar sits inside one. For how containers are laid out on a page, see [Data reports](?path=/docs/design-guidelines-patterns-data-reports--docs).

Charts are built with Highcharts, not Wonder Blocks.

## <Do /> When to use

| Use when | Example |
| --- | --- |
| Showing one chart that needs a few controls, or none | Growth over time, with a date filter and download |

## <Dont /> When NOT to use

| Don't use when | Use instead |
| --- | --- |
| Showing a table of students or items | [Data tables](?path=/docs/design-guidelines-components-data-visualization-data-tables--docs) |
| The headline is a single value | [Summary cards](?path=/docs/design-guidelines-components-data-visualization-summary-cards--docs) |
| The data needs more than about three controls | Its own page or section. See [Data reports](?path=/docs/design-guidelines-patterns-data-reports--docs). |

## Anatomy

| Part | Placement | Required |
| --- | --- | --- |
| Section heading (H2) | Above the container | Yes |
| Title (H3) | Inside, top left. States the insight. | Yes, except in empty and error states |
| Description | Below the title | When it adds context |
| Controls | Inside, top right, on the same line as the title | Optional |
| Chart | Below the title | Yes |
| Legend | Below the title, or below the chart | Only when series can't be labeled directly |
| Footer | Bottom. Data source and last-updated time. | Yes |

For the parts of the chart itself, like axes and data labels, see [Anatomy](?path=/docs/design-guidelines-foundations-data-visualization--docs#anatomy) in Data visualization.

### Headings

The section heading and title each have a different job.

| Part | Purpose | Example |
| --- | --- | --- |
| Section heading (H2) | Names the topic | "Growth over time" |
| Title (H3) | States the insight | "Students are moving up, but five have never left Beginning." |

- The section heading draws the eye down the page and tells readers what the containers below are about.
- Either heading can have a description below it. Add one only if it's truly needed.

## Controls

Controls live inside the container, at the top right, on the same line as the title. They must fit on one line without wrapping.

Controls are optional. Add one only when it helps the reader answer the chart's question.

| Control | Use when |
| --- | --- |
| Date filter | The reader may need a different time range |
| View toggle | The same data works as a chart and as a table |
| Download | The reader needs the data outside the product |

When the data needs more than about three controls, it outgrows a container. See [Own page or section](?path=/docs/design-guidelines-patterns-data-reports--docs#own-page-or-section) in Data reports.
